# Roblox Scripting Demos — Oscar Talamantes

Playable demo places from my Roblox scripting portfolio. Download a file, open it in Roblox Studio, and press Play.

## Combat Demo (`combat-demo.rbxlx`)
Server-authoritative melee combat: click-to-swing with hit detection, damage, knockback, health regen, and a dummy target. All logic in Luau, server-validated.

## Coin / DataStore Demo (`datastore-demo.rbxlx`)
Coin collection with a persistent DataStore backend: coins save on earn, on a timed autosave, and on player exit, and load back on join. Includes a live coin counter UI.
